# Penetration Testing Lifecycle

## Learning Objectives

Understand plan, scope, gate, observe, record, evaluate, and reproduce stages.

## Why This Matters

Explicit stages keep authorization and evidence separate.

## Core Concepts

Scope, discovery, action proposal, safety approval, observation, evidence, evaluation, restore.

## Terminology

A lifecycle stage is not permission to execute it.

## Mathematical / Technical Foundations

Lifecycle applies only to approved isolated lab scenarios.

## Project Mapping

This maps to runbook procedures and experiment contract.

## Security Boundaries

Stop on scope mismatch, missing approval, or evidence-loss risk.

## Common Mistakes

Skipping approval or claiming a completed run from a plan.
